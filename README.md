# Система управления библиотекой

Этот проект представляет собой REST API для управления библиотекой, созданный с использованием FastAPI и MySQL. API позволяет добавлять книги, выдавать их читателям, возвращать книги, просматривать списки книг и выдач, а также получать статистику по жанрам книг.

## Структура проекта

- main.py: Основной файл с FastAPI-приложением, содержащий endpoints для работы с библиотекой.
- database.py: Функции для взаимодействия с базой данных MySQL (подключение, добавление, выдача, возврат, получение данных).
- stats.py: Функция для анализа статистики по жанрам книг.
- forvenv/: Виртуальное окружение, содержащее все необходимые библиотеки Python.

## Требования

- Python 3.8 или выше
- Локально запущенный сервер MySQL с базой данных library_db

## Установка

1. Склонируйте репозиторий:
   ```
   git clone <URL-репозитория>
   cd <директория-репозитория>
   ```

2. Активируйте виртуальное окружение:
   ```
   source forvenv/bin/activate  # Для Linux/Mac
   forvenv\Scripts\activate     # Для Windows
   ```

   Примечание: Все необходимые библиотеки (fastapi, mysql-connector-python, pandas, uvicorn) находятся в виртуальном окружении forvenv.

3. Настройте MySQL:
   - Убедитесь, что сервер MySQL запущен.
   - Создайте базу данных library_db:
     ```
     CREATE DATABASE library_db;
     ```
   - Обновите учетные данные в database.py (по умолчанию: user="root", password="ur password") на ваши.

## Использование

1. Запустите FastAPI сервер:
   ```
   uvicorn main:app --reload
   ```

2. Доступ к API:
   - Откройте браузер или используйте инструмент вроде Postman/Curl для взаимодействия с API.
   - Документация API доступна по адресу: http://127.0.0.1:8000/docs (Swagger UI).

3. Доступные endpoints:
   - GET /: Возвращает приветственное сообщение.
   - POST /add_book?title=<название>&author=<автор>&genre=<жанр>: Добавляет новую книгу.
   - POST /loan_book?book_id=<id>&reader_name=<имя_читателя>: Выдает книгу читателю.
   - POST /return_book?loan_id=<id>: Отмечает возврат книги.
   - GET /books: Возвращает список всех книг.
   - GET /loans: Возвращает список всех выдач.
   - GET /genre_stats: Возвращает статистику по жанрам книг.

   Пример запроса (с использованием curl):
   - Добавить книгу:
     ```
     curl -X POST "http://127.0.0.1:8000/add_book?title=Война%20и%20мир&author=Толстой&genre=Роман"
     ```
   - Получить список книг:
     ```
     curl -X GET "http://127.0.0.1:8000/books"
     ```

## Схема базы данных

API создает две таблицы в базе данных library_db:

1. Таблица books:
   ```
   CREATE TABLE books (
       book_id INT AUTO_INCREMENT PRIMARY KEY,
       title VARCHAR(255),
       author VARCHAR(255),
       genre VARCHAR(50),
       is_available INT
   );
   ```
   - book_id: Уникальный идентификатор книги.
   - title: Название книги.
   - author: Автор книги.
   - genre: Жанр книги.
   - is_available: Доступность книги (1 — доступна, 0 — выдана).

2. Таблица loans:
   ```
   CREATE TABLE loans (
       loan_id INT AUTO_INCREMENT PRIMARY KEY,
       book_id INT,
       reader_name VARCHAR(255),
       loan_date VARCHAR(50),
       return_date VARCHAR(50)
   );
   ```
   - loan_id: Уникальный идентификатор выдачи.
   - book_id: ID книги, связанной с выдачей.
   - reader_name: Имя читателя.
   - loan_date: Дата выдачи.
   - return_date: Дата возврата (пустая строка, если книга не возвращена).

## Настройка

- База данных: Настройте параметры подключения к MySQL в database.py (host, user, password, database), если они отличаются.
- Пароль: Замените password="ur password" в database.py на действительный пароль MySQL.
- Формат дат: Даты выдачи и возврата автоматически форматируются как ГГГГ-ММ-ДД (например, 2025-04-13).

## Примечания

- Виртуальное окружение forvenv содержит все зависимости, поэтому установка дополнительных библиотек не требуется, если вы не добавляете новый функционал.
- Убедитесь, что сервер MySQL работает и база данных library_db создана перед запуском API.
- Статистика по жанрам (в stats.py) подсчитывает количество книг для каждого жанра на основе данных из таблицы books.
